# Skying design exploration

Audience confirmed: everyday sunset watchers, with photography details available.

Seven grounded directions, ordered by audience resonance:
1. Horizon observatory: a panoramic sky and clear viewing-window instruments.
2. Trail guide: route-like steps from choosing a place to leaving for sunset.
3. Cinema light table: large scenes and a day-by-day contact strip.
4. Camera viewfinder / The Light Finder: a single sky window, verdict and time, with restrained measurement detail.
5. Tide almanac: a compact, readable calendar of evening conditions.
6. Sky atlas: location-centered exploration and cloud strata.
7. Departure board: an upcoming-evening schedule ordered by usefulness.

Impeccable seed 07c32d5f assigned candidate 4. Six catalog challengers were evaluated against everyday audience identification and task clarity; their verdicts and retained disciplines are recorded in .impeccable/direction-options.json.

Taste settings: DESIGN_VARIANCE 7, MOTION_INTENSITY 3, VISUAL_DENSITY 4. The landing surface receives Taste Skill composition guidance. The forecast is Operate mode and follows Impeccable for task clarity. Native CSS and the existing vanilla JavaScript remain the implementation foundation.

Physical scene: someone checks a phone outdoors before sunset, so default light surfaces need strong contrast; a system dark theme supports dim evening use. Photography windows and conditions are secondary to the sunset verdict.
