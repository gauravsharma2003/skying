# Skying

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Everyday sunset watchers deciding whether and when to head outside. Photography details remain available as secondary information. Confirmed by the user on 2026-09-17.

## Product Purpose

Help people find a location's sunset quality, sunset time, viewing window, and seven-day outlook.

## Capabilities and Constraints

The existing implementation provides location search, device location, a score out of 100, a verbal verdict, weather-based explanations, horizon clarity, and daily forecasts. Preserve real data and location routes. The project uses HTML, CSS, JavaScript, and a Cloudflare Worker. Backend files are being changed independently; the redesign must preserve those changes.

## Brand Commitments

Keep the name Skying. The user requested an innovative, distinctive responsive redesign using Impeccable and Taste Skill, with both planning and implementation.

## Evidence on Hand

Existing interface: index.html and style.css. Existing client behavior: app-loader.js and app-chunks. Emerging source modules: src/. No testimonials or commercial performance claims supplied.

## Product Principles

- Answer whether the sunset is worth watching before presenting weather detail.
- Make choosing a place and a day straightforward on every device.
- Distinguish forecasts and uncertainty from observed conditions.
- Keep photography details available without making the everyday task harder.
